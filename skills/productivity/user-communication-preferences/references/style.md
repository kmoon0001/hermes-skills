# Style Preferences (Session Summary)

- **No markdown** in any output; plain text only.
- **ALL CAPS** for casual messages when the user asks for it.
- **Ultra‑concise**: bottom‑line diagnosis first, fix second. No verbose explanations.
- **Pitfalls**: never include markdown formatting, never use bullet list syntax; use simple line labels.
- **Embedding**: treat any "stop doing X" directive as a hard rule and add it to the skill's Pitfalls section.
