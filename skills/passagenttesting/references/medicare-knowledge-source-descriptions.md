# Medicare & Regulatory Knowledge Source Descriptions

Microsoft Learn best-practice descriptions for CMS Medicare documents used across PT_Specialist, OT_Specialist, and SLP_Specialist agents. Each description follows the pattern: what it contains → when to use it → key topics covered.

## Medicare Benefits Policy Manual, Chapter 15

> Provides CMS Medicare Benefit Policy Manual Chapter 15 on covered medical services. Use when auditing skilled therapy documentation for Medicare Part B coverage, determining reasonable and necessary criteria, or verifying qualifying service definitions. Covers skilled PT, OT, and SLP services, outpatient therapy thresholds, the therapy cap exceptions process, and supervision requirements.

## Medicare Program Integrity Manual, Chapter 3: Medical Review & Program Integrity

> Provides CMS Medicare Program Integrity Manual Chapter 3 on verifying potential fraud and abuse under Medicare. Use when auditing documentation for medical review policies, overpayment identification, provider compliance, or integrity program requirements. Covers prepayment review, postpayment review, provider enrollment screening, Medicare Secondary Payer verification, and recovery audit contractor processes.

## Medicare Program Integrity Manual, Chapter 5: Provider Enrollment

> Provides CMS Medicare Program Integrity Manual Chapter 5 on provider enrollment and screening. Use when auditing provider enrollment applications, verifying provider eligibility, or assessing compliance with Medicare enrollment requirements. Covers provider enrollment screening levels, provider disclosure requirements, re-enrollment bar policies, and revocation or deactivation of billing privileges.

## Medicare Claims Processing Manual, Chapter 5

> Provides CMS guidelines for processing Medicare claims, specifically Chapter 5 covering professional and technical requirements for therapy services. Use when auditing billing compliance, verifying correct coding, or validating therapy claim submissions. Covers outpatient rehabilitation billing, therapy cap exceptions, and claims submission standards.

## Medicare Secondary Payer Manual — Therapy

> Provides CMS Medicare Secondary Payer (MSP) rules as they apply to therapy services. Use when determining whether Medicare is primary or secondary payer for therapy claims, verifying coordination of benefits, or auditing MSP compliance in outpatient and SNF settings. Covers billing order requirements, conditional payments, and recovery processes for therapy services.

## 42 CFR Section 424.24 — Conditions of Payment for Therapy Services

> Provides the Code of Federal Regulations Title 42, Volume 3, Section 424.24 governing conditions of payment for outpatient therapy services. Use when verifying regulatory compliance for Medicare Part B therapy claims, auditing signature requirements, or confirming that documentation meets federal conditions for payment. Covers plan of care requirements, certification and recertification periods, and physician signature rules.

## 2025 Part B MSCA Audit Worksheet

> Provides the standardized clinical audit worksheet for 2025 Medicare Part B Medical Review and Skilled Care Analysis (MSCA). Use when conducting prepayment or postpayment review of therapy documentation for medical necessity, skilled care justification, and functional progress. Covers audit scoring criteria, documentation deficiency categories, and evidence-of-medical-necessity standards.

## CMS Medicare Learning Network — Therapy

> Provides CMS Medicare Learning Network educational resources for therapy services compliance. Use when training clinicians on Medicare billing rules, documentation requirements, or regulatory updates. Covers outpatient rehabilitation therapy services, medical necessity documentation, and common compliance pitfalls.

## AOTA/APTA/ASHA Consensus Statement on Therapy Documentation

> Provides the interorganizational consensus statement from AOTA, APTA, and ASHA on documentation standards for therapy services. Use when auditing OT documentation for compliance with professional standards across disciplines. Covers documentation content requirements, signature policies, frequency-of-treatment justification, and interprofessional communication standards.

## Description Writing Rules (from Microsoft Learn)

1. **Active voice, present tense** — "Provides CMS Medicare..." not "This document contains..."
2. **1-2 sentences** — What it is + when to use it
3. **Include keywords** matching user intent (e.g., "reasonable and necessary", "skilled therapy", "supervision requirements")
4. **Disambiguate similar sources** — Each description must be unique and tell the agent what this source covers that others don't
5. **No file extensions** — No .pdf, .md, .docx in names or descriptions
6. **No auto-generated text** — Replace "This knowledge source searches information contained in [filename]" with a real description
