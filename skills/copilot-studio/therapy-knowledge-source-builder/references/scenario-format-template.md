## Format Rules

1. **Every scenario MUST have "SNF Relevance"** — this is what makes it SNF-specific vs. general clinical content
2. **Use real numbers:** ROM degrees, MMT grades, O2 sats, distances, assist levels, outcome measure scores, timeframes
3. **Reference governing bodies:** APTA Domains (KP 1-4, CO 1-2, PC 1-17, PR 1-8, PM 1-9, RP 1-2, EL 1-6, SB 1-6), AOTA Standards (1-5), ASHA DCVT / Practice Portal
4. **Hard/Expert scenarios:** Must include multiple comorbidities, atypical presentations, ethical dimensions, or conflicting clinical data
5. **Wrong answers must be PLAUSIBLE:** Each distractor should represent a real clinical error that practicing therapists actually make
6. **Patient presentations: 2-4 sentences max.** If longer, the scenario is too complex — split it
7. **One clinical decision per scenario.** Don't ask "what should you do AND why" — that's two questions
