# MCP Spec 2026-07-28 RC

**Source:** https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/
**Final spec ships:** July 28, 2026
**Status:** Release candidate (breaking changes from 2025-11-25)

## Key Changes

### Stateless Core
- No more `initialize` handshake or session lifecycle
- Servers behind plain round-robin load balancers (no sticky sessions needed)
- Clients cache `tools/list` responses based on `ttlMs` from server
- `Mcp-Method` header for traffic routing at the gateway
- Routable, cacheable, traceable on standard HTTP infrastructure

### Extensions Framework
- Capabilities like Tasks and MCP Apps ship on their own timeline
- **MCP Apps**: server-rendered user interfaces (server renders UI, client displays)
- **Tasks**: long-running work graduates from experimental to a formal extension

### Authorization Hardening
- Aligns more closely with OAuth/OpenID Connect deployments
- Stricter authorization model

### Deprecations
- **Roots** — deprecated
- **Sampling** — deprecated
- **Logging** — deprecated

### Tool Schema
- Full JSON Schema 2020-12 for tools (upgraded from earlier draft)

## Migration Impact
- Breaking change from 2025-11-25
- SDKs (Python v2.0.0a3, TS server-legacy v2.0.0-alpha.3) already reflect stateless negotiation
- Migration guide available with the final spec
